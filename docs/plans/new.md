# Adaptive Learning Feature - Full UI Implementation

## Project Context

You are implementing the **frontend UI** for an Adaptive Learning feature that will be integrated into an existing educational app. This feature allows students to:

1. Upload PDF documents (textbooks, syllabi)
2. System automatically extracts concepts and builds a Knowledge Graph (DAG)
3. Learn through adaptive exercises selected by an RL-based system
4. Get AI chatbot support when stuck
5. Track progress through gamification

**IMPORTANT**: Follow the existing app's design system. All components should match the current visual language.

## Screen Specifications

### 1. Upload PDF Screen (`/adaptive-learning/upload`)

**Purpose**: Entry point where students upload their learning materials.

**Layout**:

- Header with back button and title
- Large drag-and-drop zone (centered)
  - Accept: PDF files only
  - Max size: 50MB
  - Visual states: default, hover, uploading, error
- Recent uploads section below (grid of cards)
  - Each card shows: document name, progress %, concept count
  - Click to resume learning

**Components needed**:

- `PDFDropzone` - Drag & drop upload area
- `DocumentCard` - Recent upload card with progress
- `UploadProgress` - Upload progress indicator

**States to handle**:

- Empty (no previous uploads)
- With history (show recent documents)
- Uploading (progress bar)
- Error (invalid file, too large)

### 2. Processing Screen (`/adaptive-learning/processing`)

**Purpose**: Show progress while system processes PDF and builds Knowledge Graph.

**Layout**:

- Centered content
- Animated document icon
- Progress bar with percentage
- Step-by-step checklist:
  1. ✓ Đọc nội dung PDF
  2. ✓ Trích xuất khái niệm (N found) - update N in real-time
  3. ◐ Xây dựng Knowledge Graph...
  4. ○ Tạo lộ trình học tập
  5. ○ Chuẩn bị bài tập đầu tiên
- Tip box at bottom (rotating tips about the process)

**Components needed**:

- `ProcessingProgress` - Main progress container
- `StepIndicator` - Individual step with status icon
- `TipBox` - Rotating helpful tips

**States**:

- Each step: pending (○), processing (◐ animated), done (✓), error (✗)
- Auto-navigate to Dashboard when complete

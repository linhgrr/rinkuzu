# Security Policy

## Supported Versions

Only the latest version on the default branch is supported.

## Reporting A Vulnerability

Do not open a public issue for security findings.

Report vulnerabilities privately to the project maintainers and include:

1. A clear description of the issue.
2. Steps to reproduce it.
3. Expected impact.
4. Any suggested remediation if available.

Secrets must stay in local or deployment-managed environment variables and must never be committed.

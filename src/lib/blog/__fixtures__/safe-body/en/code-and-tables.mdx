## Markdown that looks like code but is not

| Construct | Example |
| --------- | ------- |
| Expression | `{props.value}` |
| Tag | `<div>` |

Inline `import x from 'y'` and `<Foo />` are code spans. An escaped \{ brace and \<b\> tag render literally.
